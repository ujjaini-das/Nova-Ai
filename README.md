# Nova AI 🤖

A full-stack AI chatbot built using HTML, CSS, JavaScript, Node.js, Express, and Groq API.

## Live Demo

https://nova-ai-ce5y.onrender.com

## Features

* AI-powered chat responses
* Voice input using Speech Recognition API
* Dark/Light mode
* Chat history
* Markdown support
* Copy response button
* Responsive design
* Secure backend API integration

## Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js

### AI

* Groq API
* Llama 3.3 70B

## Installation

### Clone Repository

```bash
git clone https://github.com/ujjaini-das/Nova-Ai.git
```

### Install Dependencies

```bash
cd backend
npm install
```

### Configure Environment

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key
PORT=3000
```

### Run Project

```bash
npm start
```

Open:

```text
http://localhost:3000
```
